# 青丘九尾狐 V4.1 项目源码

Godot 4.7.2 Standard 打开 project.godot，首次导入后按 F5。
入口：Scenes/Qingqiu/QingqiuArena.tscn。Forward+，1920×1080。

Enter开始／继续；WASD移动，空格冲刺；左键/J/1挥击，2横扫，3护魂，右键/4重击。R从阶段存档点满血重试，Tab回预览。F8开发测试下F6/F7直达P2/P3，不覆盖正式进度。滚轮缩放，B减弱特效，M静音音乐和音效，V试听阶段狐鸣。开场Enter/左键/Esc跳过。

P1通关保存P2，P2通关保存P3；存档使用user://，交付不含玩家存档。

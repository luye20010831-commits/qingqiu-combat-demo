## 运行

打开 `project/project.godot`，等待首次资源导入完成，按 F5。入口为 `Scenes/Qingqiu/QingqiuArena.tscn`，Forward+，逻辑分辨率 1920×1080。

| 操作 | 按键 |
| --- | --- |
| 正常开始／继续 | Enter；首次 P1 有约 4.6 秒开场 |
| 跳过开场 | 演出中 Enter、左键或 Esc |
| 移动／冲刺 | WASD／空格 |
| 挥击／横扫／护魂／重击 | 左键／J／1，2，3，右键／4；也可点击图标 |
| 重试／回到预览 | R／Tab |
| 镜头／减弱特效／音乐静音 | 滚轮／B／M |
| 开发测试 | F8 开启后，F6／F7 从 P2／P3 开始 |

正常游玩打完 P1 保存到 P2，打完 P2 保存到 P3，重新打开或死亡重试从存档点满血、清冷却开始；连续过阶段只恢复 25 血。开发入口不覆盖正式存档。正式存档使用 Godot `user://`，包内未附带任何玩家存档。

## 当前参数

玩家 120 HP，挥击／横扫／重击 10／24／42，护魂冷却 7 秒；Boss 1850／2000／2000 HP。P2 四波落焰 26／25／26／25，共 102 处；P3 九柱三拍共 27 柱，八轮顺时弹幕共 128 枚。保留三首阶段音乐，恢复选定攻击／命中／燃烧及阶段／转场声音，共13份当前可用独立音效；25份已删除AI程序合成音源仍不恢复。M同时静音音乐与音效，V试听当前阶段狐鸣；附带视频为有声1.5倍速版本。

## 录像与试玩边界

录像从本包源码重新采集，使用真实引擎渲染、游戏混音、接触和状态规则；成片1.5倍速，不代表游戏运行速度。录制脚本安排站位与出招、分段重置生命／冷却，阶段及胜负展示包含尾血快进，字幕均有说明。玄焰段使用正式 120 HP；存档展示使用独立测试文件。视频不代表本人完整通关或最终难度验收。

本人调参前在P2未通关，认为玩家偏弱；后续已亲自体验全部三阶段并打完P3，反馈“简单多了，打得过了”。这次迭代是降低过高压力、使战斗可完成，没有完成系统难度曲线。考虑时间与工作量，本次聚焦现有玩家原型与一场 Boss 战，多职业暂不制作。

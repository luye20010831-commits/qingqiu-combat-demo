# 青丘九尾狐 V4.1 战斗设计

选择九尾狐兽形 Boss，自搭青丘林地，以“美丽危险、隐藏意图”为方向。
标志机制为惑心：爱心接触后改变控制或视野，玩家需在防御、走位、取光和近战输出之间判断。

## 核心机制与玩家判断

P1 短暂失控引导玩家靠近幼狐，P3 变为仍可主动寻光解除的视野遮挡。危险通过身体前摇、头顶浮纹和飞行轨迹表达；地面攻击范围图形均隐藏。成功应对后能避伤、解魅，或利用收招接近反击。

| 阶段 | 行为与招式关系 | 预期应对 |
| --- | --- | --- |
| P1 单尾幼狐 | 轻跃追逐与佯退；抓挠、锁方向冲撞、单尾横扫。一颗持续追踪的爱心实际接触后，使玩家失控靠近 1.2 秒，并有较轻粉紫雾。 | 读压身、抬爪、卷尾与浮印；侧向冲刺躲冲撞后反击。已成形的护魂可抵消爱心。 |
| P2 双尾迷雾 | 三种远距普通攻击与三种三波弹幕交替，游走和隐身改变接近机会。玄焰倾天四波共 102 落点，余焰 2.8 秒，离地后仍有 3 秒灼烧。 | 持续读后续波次与锁定方向。显形后有 1.4 秒原地窗口，整轮退火后 2.4 秒；躲落焰后再贴近输出。 |
| P3 九尾金瞳 | 四颗飞行爱心接触后遮挡视野，蓝光点可解魅；九柱三拍横纵扫场。第五次施法归中跃落，再连续八轮顺时狐焰，每轮留相邻缺口。 | 躲爱心或提前护魂；中魅后主动寻光。读火柱节拍与旋转缺口，最后一轮后再近身反击。 |

## 玩家工具

- 挥击 / 横扫：10 / 24 伤害；0.14 / 0.28 秒接触；冷却 0.4 / 3.5 秒。
- 护魂：0.32 秒成盾，持续 3 秒；伤害减半并抵消爱心，冷却 7 秒。
- 重击 / 冲刺：重击 42 伤害、0.52 秒接触、冷却 2.2 秒；冲刺可取消未命中出手。

## 节奏预算

玩家 120 生命，阶段恢复 25；Boss 1850 / 2000 / 2000 生命。2 / 3 / 3 分钟为参考预算，不是已验证通关用时。当前血量和窗口为 AI 首轮调参工作值，本人已复测并打完P3，阶段耗时未单独计量。

## 本人观察与范围取舍

调参前，我的试玩停在 P2。我觉得战斗本身挺好玩，主要不足是玩家能力偏弱，也更喜欢有挑战的战斗。考虑时间与工作量，本次先完成一套近战四技能原型和一场三阶段 Boss 战，暂不扩展职业；多职业只作为后续探索方向。后续本人已体验全部三阶段并打完P3，反馈“简单多了，打得过了”。

## 迭代一

反击收益与持续压力：依据上述反馈，首轮把玩家生命 100→120、横扫 18→24、重击 32→42、护魂冷却 8→7 秒；P2 游走放慢，显形与退火后改为原地反击窗口，缩短余焰和灼烧。V4.1 再按数量 ×0.8 的要求，把四波落焰 128→102。具体工作值与实现由AI补全。本轮降低过高压力后，本人复测反馈“简单多了，打得过了”。

## 迭代二

规则与危险信号：按反馈把 P1 魅惑改为追踪爱心、短暂失控及护魂抵消；P3 保留四心、光点解魅和高压弹幕，视障由八秒减为五秒。将几何地面提示改为身体前摇与头顶浮纹，眼位采用同母版拆层，前摇、步态与尾部联动持续修正。

## 进入存档与重试

正常 Enter 开战有 4.6 秒“雾中来客”，可用 Enter / 左键 / Esc 跳过。P1 通关保存到 P2，P2 通关保存到 P3；重进和 R 从正式存档点满血重试。WASD 移动、空格冲刺、左键 / 1 挥击、2 横扫、3 护魂、右键 / 4 重击。F8 开发测试下 F6 / F7 直达 P2 / P3，且不覆盖正式存档。
